# IsaHo VPN

VPN شخصی با Xray و مدیریت کامل از طریق ربات تلگرام.

## معماری

| کانفیگ | مسیر | کاربرد |
|---|---|---|
| ⚡ **VLESS + Reality + Vision** (پورت 443) | مستقیم به IP سرور | سریع‌ترین؛ ترافیک شبیه اتصال TLS به یک سایت معتبر است |
| ☁️ **VLESS + XHTTP + TLS** (پورت 2053) | از طریق CDN کلادفلر | پشتیبان؛ اگر IP سرور فیلتر شود هم کار می‌کند |
| 📥 **سابسکریپشن** (پورت 2096) | از طریق کلادفلر | هر دو کانفیگ + حجم و تاریخ انقضا داخل اپ |

علاوه بر این: BBR و تنظیمات شبکه برای سرعت بیشتر، بلاک شدن تورنت و سایت‌های `.ir` روی سرور
(تا IP سرور در لاگ سایت‌های داخلی ثبت نشود)، و آمار مصرف لحظه‌ای هر کاربر.

## نصب

**۱. کلادفلر** (برای دامنه/ساب‌دامنه‌ای مثل `cdn.example.com`):
- DNS: رکورد A به IP سرور با **Proxy روشن** (ابر نارنجی)
- SSL/TLS → حالت **Full**
- Network → WebSockets و gRPC روشن

**۲. روی سرور** (Ubuntu 22.04/24.04 یا Debian 12، خارج از ایران):
```bash
apt update && apt install -y git
git clone https://github.com/IsaHo/IsaHo.git
bash IsaHo/vpn/install.sh
```
نصب‌کننده توکن ربات، آیدی عددی ادمین و دامنه را می‌پرسد. بعد در تلگرام به ربات `/start` بدهید.

## سرور واسط ایران (پیشنهادی وقتی اتصال مستقیم فیلتر است)

روی یک VPS ایرانی (Ubuntu)، با تانل SSH (چند اتصال موازی + HAProxy):
```bash
curl -fsSL https://raw.githubusercontent.com/IsaHo/IsaHo/main/vpn/relay.sh | bash -s ssh <IP-سرور-خارج> 3
```
خط `AUTHORIZED` که چاپ می‌کند را یک بار روی سرور خارج اجرا کنید. سابسکریپشن هم از `http://IP-ایران:2096` سرو می‌شود.
بعد در ربات: ⚙️ تنظیمات ← 🇮🇷 سرور واسط ← `IP:443`. کاربران سابسکریپشن را آپدیت کنند.

## امکانات ربات

- ساخت کاربر با حجم و مدت دلخواه + لینک‌ها، QR و سابسکریپشن
- لیست کاربران با وضعیت رنگی (🟢 فعال، 🟡 رو به اتمام، 🔴 غیرفعال) و جستجو
- تمدید، افزایش حجم، ریست مصرف، تغییر UUID، فعال/غیرفعال، یادداشت، حذف
- اعمال تغییرات **بدون قطع شدن بقیه کاربران** (از طریق Xray API)
- غیرفعال‌سازی خودکار با تمام شدن حجم یا زمان + هشدار در ۹۰٪ حجم یا ۲ روز مانده
- اتصال کاربران به ربات با لینک اختصاصی تا خودشان مصرفشان را ببینند و هشدارها را بگیرند
- پیام همگانی به کاربران متصل
- وضعیت سرور (CPU، RAM، دیسک، پرمصرف‌ترین کاربران)
- بکاپ خودکار روزانه به تلگرام؛ بازگردانی با فرستادن فایل `.db` به ربات
- تنظیم IP تمیز کلادفلر برای کانفیگ CDN، بدون نیاز به فرستادن دوباره لینک‌ها

## سرور خارج دوم (پشتیبان)

⚙️ تنظیمات ← 🌍 سرورهای خارج ← ➕ (مثلاً `FR | 202.133.88.44 | fr.zkim.app`)، بعد دستوری که ربات می‌دهد را روی آن سرور اجرا کنید.
سرور دوم همان کاربران و کلیدها را هر دقیقه از ربات می‌گیرد و مصرف را برمی‌گرداند.
برای تانل از ایران به هر دو: `relay.sh ssh <IP-آلمان>,<IP-پاریس> 3` و خط AUTHORIZED را روی هر دو سرور خارج اجرا کنید.

اگر سرور اصلی از دست رفت: روی سرور دوم `isaho-takeover` (از آخرین نسخه‌ی یدک ساعتی، ربات را آنجا بالا می‌آورد).

## مدیریت سرورهای ایران از ربات

هر سرور ایران هر دقیقه از داخل تانل وضعیتش را به ربات گزارش می‌دهد:
⚙️ تنظیمات ← 🛰 سرورهای ایران (وضعیت تانل‌ها، بار، RAM، ترافیک، نسخه) با دکمه‌های ریستارت و آپدیت.

## فروشگاه

پنل ← 🛒 فروشگاه: پلن‌ها، اطلاعات کارت، کد تخفیف، نماینده‌ها (با درصد تخفیف)، اکانت تست، درصد پاداش دعوت.
مشتری‌ها در ربات پلن را می‌خرند، کارت‌به‌کارت می‌کنند و عکس رسید می‌فرستند؛ مدیرها با یک دکمه تأیید می‌کنند
و اکانت (یا تمدید) خودکار تحویل داده می‌شود. پاداش دعوت به کیف پول می‌رود و در خرید بعدی کم می‌شود.

## امنیت سرورها

روی هر دو سرور: `bash vpn/harden.sh <IP-سرور-دیگر>` (fail2ban، و اگر کلید SSH دارید ورود با رمز بسته می‌شود).

## دستورات سرور

```
isaho status     وضعیت سرویس‌ها
isaho logs       لاگ زنده
isaho restart    ریستارت
isaho update     آپدیت (کاربران و کلیدها حفظ می‌شوند)
isaho env        ویرایش تنظیمات
isaho uninstall  حذف کامل
```

## اپ‌های پیشنهادی

- iOS: Streisand، V2Box، Hiddify
- ویندوز/مک: Hiddify، v2rayN
